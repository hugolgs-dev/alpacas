# alpacas

A Computer Algebra System (CAS) written in Gleam. 
The goal of this project is to provide a simple and easy-to-use tool for performing symbolic mathematics in Gleam. It's very early in development, and the API is very far from being stable. Don't use this for now. But have a look if you wish :)

# Status

Early development. The API unstable. v.0.0.1.
